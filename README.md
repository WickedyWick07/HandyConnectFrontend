# Handy Connect – Frontend

Handy Connect is a web application that connects clients with skilled handymen for various services such as home repairs, furniture assembly, and maintenance work.

This repository contains the **frontend** of the application, built with a focus on usability, responsiveness, and real-time interaction.

## Features
- User registration and authentication
- Role-based access (Admin & Customer)
- User profiles
- Browse and book handyman services
- Real-time user messaging using Socket.IO
- Responsive design for mobile and desktop
